# Mood-Based AI

Mood-Based AI is an experimental project space for exploring models and interactions that respond to mood-related inputs. The repository currently centers on the `CHATMODELS` workspace, making it a useful base for comparing conversational model behavior and mood-aware prompting.

## Focus areas

- Mood classification and interpretation
- Context-aware conversational responses
- Prompt and model comparisons
- Safe, transparent handling of uncertain emotional signals

## Repository layout

```text
CHATMODELS/     Model experiments, prompts, and related artifacts
```

## Working with the project

Begin by reviewing the notebooks, scripts, or model configuration inside `CHATMODELS`. Keep experiments reproducible by recording the model name, prompt version, input assumptions, and evaluation notes alongside results.

## Responsible use

Mood inference is probabilistic and should never be presented as a diagnosis or a definitive statement about a person's mental state. Avoid collecting sensitive personal data, obtain consent for user-provided text, and provide a clear path for users to correct or reject an inference.

## Contributing

Add a short experiment note for each new model or prompt, include representative inputs and expected behavior, and avoid committing credentials, private conversations, or generated artifacts that contain personal data.
